# AI System Design — The 7 Concepts

A simple-English study guide to the 7 concepts every AI system design interview asks about, from the Instagram Reel by notaboringdeveloper (Anmol Agarwal):

1. RAG — Give the Model the Right Knowledge
2. Fine-Tuning — Teach the Model How to Behave
3. Evals — Know If the System Works
4. Agents — Systems That Plan, Use Tools, and Act
5. Caching — Make It Faster and Cheaper
6. User Feedback Loops — Learn From Real Users
7. Guardrails — Control What the System Can Do

Live site: https://parasdhawan17.github.io/ai-system-design-7-concepts/

Each concept page: the big idea, how it works, key details, common failures, an interview line, and a quiz. Plus a one-page Cheat Sheet with a sample system-design answer.
