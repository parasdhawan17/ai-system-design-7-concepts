Concept 4 of 7

Agents — Systems That Plan, Use Tools, and Act

An agent is more than a chatbot. It plans steps, calls tools, checks results, and keeps going until the job is done.

THE BIG IDEA

From answering to doing

A chatbot answers once. An agent works on a goal over many steps.

It breaks the goal into steps. It calls tools. It reads the results. It changes its plan if needed. It stops when the job is done.

Note: the Reel’s card for this concept could not be read clearly, so this chapter teaches the standard study material for Agents in the same simple style.

THE LOOP

Plan, act, observe, repeat

  1. Plan: The model reads the goal and picks the next step.
  2. Act: It calls a tool: search, code, database, API, browser.
  3. Observe: It reads the tool result.
  4. Repeat: It plans again with the new facts, until the goal is met or a limit is hit.
PartRole
ModelThe brain. It reasons and decides.
ToolsThe hands. They do real work in the world.
MemoryShort-term: the current conversation. Long-term: stored facts and past results.
Harness / scaffoldThe system around the model. It runs the loop, passes tool results, and enforces limits.
DESIGN CHOICES

What interviewers probe

  • Single agent vs multi-agent: One agent is simpler. Many agents can split big work, but they add cost and coordination problems. Start with one.
  • Step and cost limits: Set max steps, max time, and max budget. An agent without limits can loop forever.
  • Checkpoints: Save state at safe points. A long job can resume after a failure.
  • Human in the loop: Ask a human to approve risky or irreversible actions.
Key riskErrors compound. 95% success per step over 20 steps is only about 36% success overall. Short plans, verification steps, and retries matter.

Quick quiz

  1. Why is an agent harder to control than a single LLM call?
Show answer

It acts over many steps. Each step can add an error, and errors compound. It also changes real state, so mistakes have real effects.
